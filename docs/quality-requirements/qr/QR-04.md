# QR-04: Serve An Unmodified OpenAI SDK Client

An application using the official OpenAI Python SDK completes a non-streaming chat request through the gateway by changing only its base URL and API key.

- **Status:** Active
- **Characteristic:** Compatibility
- **Sub-characteristic:** Interoperability
- **Business importance:** Medium
- **Technical risk:** Low

## Scenario

### Source

A developer's application that already calls the OpenAI Chat Completions API through the official OpenAI Python SDK.

### Stimulus

The application is pointed at the gateway's `/v1` base URL with its gateway client token as the API key and sends a non-streaming chat completion for an allowed model.

### Environment

The gateway runs with client authentication enabled and one configured provider, per [`CON-01`](../../product-vision.md#con-01).

### Artifact

The OpenAI-compatible endpoints `POST /v1/chat/completions` and `GET /v1/models`.

### Response

The gateway shall return a response the SDK parses as a chat completion with the assistant's text.

### Response Measure

With no change to the application code other than the base URL and API key, the SDK call returns without raising an exception and its first choice's message content equals the provider's answer after the configured middleware.
