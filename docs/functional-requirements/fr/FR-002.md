# FR-002: Mask Phone Numbers Throughout The Conversation

- **Status:** Active
- **Traces to:** [`US-02`](https://github.com/iteam7/gateway7/issues/31), [`DEC-012`](../../decisions.md#dec-012)
- **Containers:** `gateway`

## Behavior

When the phone-masking middleware is enabled, the gateway shall replace every phone number of the three supported shapes with `[PHONE]` in every message of the conversation, of every role, before the request reaches the provider.

The gateway shall leave text that contains none of the supported shapes unchanged.

## Acceptance Criteria

### AC-01

| Message sent by the client | Text the provider receives |
| --- | --- |
| `+7 900 000-00-00; 8 (900) 000-00-00; +79000000000` | `[PHONE]; [PHONE]; [PHONE]` |
| `Order ORDER-2026-1001 shipped on 2026-10-08` | `Order ORDER-2026-1001 shipped on 2026-10-08` |

### AC-02

Given a three-message conversation whose first user message contains `+7 900 000-00-00` and whose assistant message contains `8 (900) 000-00-00`, when it is sent, then the provider receives `[PHONE]` in both earlier messages and none of the original numbers.
