# FR-008: Generate A Middleware Starter Package

- **Status:** Active
- **Traces to:** [`US-09`](https://github.com/iteam7/gateway7/issues/38), [Repository owner task #297](https://github.com/iteam7/gateway7/issues/297), [ADR-012](../../architecture/adr/ADR-012.md)
- **Containers:** `gateway`
- **Changed:** 2026-11-17, the owner's task #297 adds explicit guard/redaction presets, project metadata, local author/agent instructions and profile-aware fixtures with a dependency on the helper-bearing gateway build.

## Behavior

When a plugin author runs `gateway7 plugin init` with a valid package name and an existing parent directory, the gateway shall create an installable package with an API version 2 middleware, a gateway configuration that uses it, and synthetic fixtures that pass against it.
The author shall be able to select a request guard or a text redaction preset, and the generated project shall include profile declarations, local instructions for authors and coding agents, and a minimum gateway dependency that supplies its imports.

When the target directory already exists, the gateway shall refuse to create the package and shall leave the existing directory unchanged.

## Acceptance Criteria

### AC-01

Given an empty working directory, when the author runs `gateway7 plugin init company_mask --directory .`, then `company_mask/` contains `pyproject.toml`, `gateway.yaml`, `fixtures.json` and the package `gateway7_plugin_company_mask/plugin.py`, and FR-007's check on those files exits with code 0.

### AC-02

Given an existing `company_mask/` directory, when the same command runs, then it exits with a non-zero status and the directory's files are unchanged.

### AC-03

Given a reviewed installed gateway wheel without its source checkout, when an author generates either preset, then the generated instructions identify the gateway version and supported profiles, document commands that execute in that installed environment, and permit a synthetic red-to-green policy change without editing gateway core files.
Building and normally installing that package makes it importable from another directory.
