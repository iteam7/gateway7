# FR-008: Generate A Middleware Starter Package

- **Status:** Active
- **Traces to:** [`US-09`](https://github.com/iteam7/gateway7/issues/38)
- **Containers:** `gateway`

## Behavior

When a plugin author runs `gateway7 plugin init` with a valid package name and an existing parent directory, the gateway shall create an installable package with an API version 2 middleware, a gateway configuration that uses it, and synthetic fixtures that pass against it.

When the target directory already exists, the gateway shall refuse to create the package and shall leave the existing directory unchanged.

## Acceptance Criteria

### AC-01

Given an empty working directory, when the author runs `gateway7 plugin init company_mask --directory .`, then `company_mask/` contains `pyproject.toml`, `gateway.yaml`, `fixtures.json` and the package `gateway7_plugin_company_mask/plugin.py`, and FR-007's check on those files exits with code 0.

### AC-02

Given an existing `company_mask/` directory, when the same command runs, then it exits with a non-zero status and the directory's files are unchanged.
