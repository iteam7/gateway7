# FR-005: Check The Answer Before Delivery

- **Status:** Active
- **Traces to:** [`US-05`](https://github.com/iteam7/gateway7/issues/34), [`DEC-016`](../../decisions.md#dec-016), [`ADR-002`](../../architecture/adr/ADR-002.md), [`ADR-005`](../../architecture/adr/ADR-005.md)
- **Containers:** `gateway`
- **Changed:**
  - 2026-10-30: linked the guarded provider-stream and agent extension in ADR-005; the existing behavior and criterion identifiers are retained.
  - 2026-11-05: clarified admission of the explicitly user-requested early mode; full-response policy behavior and existing criterion identifiers are retained.

## Behavior

When a content-policy middleware configured with action `redact` on the response phase matches one of its terms in the provider's answer, the gateway shall replace each match with the configured replacement before the client receives the answer.

When the answer contains none of the terms, the gateway shall deliver it unchanged.

When a response-phase policy configured with action `block` matches the answer, the gateway shall return the safe `policy_denied` error instead of the answer.

When a client explicitly requests early delivery but an active policy requires response processing, the gateway shall reject that mode before invoking the provider rather than omit the configured policy.
The default buffered path retains the full-answer checks above; the separate request-only mode is specified by [FR-013](FR-013.md).

## Acceptance Criteria

### AC-01

Given a response-phase policy with term `SECRET-TEST`, action `redact` and replacement `[removed]`, when the provider answers `Answer SECRET-TEST`, then the client receives `Answer [removed]`.

### AC-02

Given the same policy, when the provider answers text without `SECRET-TEST`, then the client receives the provider's answer unchanged.

### AC-03

Given a response-phase policy with action `block`, when the provider's answer contains its term, then the client gets HTTP 403 with error code `policy_denied` and the provider's call count is one.

### AC-04

Given an active reference policy configured for `response` or `both`, when a client sends a streaming request with `X-Gateway7-Stream-Mode: early` and no earlier request hook denies it, then the client gets HTTP 400 and the provider's call count is zero.
An earlier request-hook denial instead returns HTTP 403 with `policy_denied`, also with zero provider calls.
Omitting that header preserves AC-01 through AC-03; no early request disables or silently skips the response policy.
