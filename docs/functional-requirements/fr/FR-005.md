# FR-005: Check The Answer Before Delivery

- **Status:** Active
- **Traces to:** [`US-05`](https://github.com/iteam7/gateway7/issues/34), [`DEC-016`](../../decisions.md#dec-016), [`ADR-002`](../../architecture/adr/ADR-002.md)
- **Containers:** `gateway`

## Behavior

When a content-policy middleware configured with action `redact` on the response phase matches one of its terms in the provider's answer, the gateway shall replace each match with the configured replacement before the client receives the answer.

When the answer contains none of the terms, the gateway shall deliver it unchanged.

When a response-phase policy configured with action `block` matches the answer, the gateway shall return the safe `policy_denied` error instead of the answer.

## Acceptance Criteria

### AC-01

Given a response-phase policy with term `SECRET-TEST`, action `redact` and replacement `[removed]`, when the provider answers `Answer SECRET-TEST`, then the client receives `Answer [removed]`.

### AC-02

Given the same policy, when the provider answers text without `SECRET-TEST`, then the client receives the provider's answer unchanged.

### AC-03

Given a response-phase policy with action `block`, when the provider's answer contains its term, then the client gets HTTP 403 with error code `policy_denied` and the provider's call count is one.
