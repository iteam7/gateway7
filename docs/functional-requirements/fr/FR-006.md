# FR-006: Restrict Each Client To Its Allowed Models

- **Status:** Active
- **Traces to:** [`US-07`](https://github.com/iteam7/gateway7/issues/36), [`CON-04`](../../product-vision.md#con-04), [`ADR-003`](../../architecture/adr/ADR-003.md)
- **Containers:** `gateway`

## Behavior

When authentication is enabled and a request carries no bearer token or a token that matches no configured client, the gateway shall return an authentication error and shall make no provider call.

When an authenticated client requests a model outside its configured allowlist, the gateway shall return an access error before running any middleware or calling the provider.

When an authenticated client requests the model list, the gateway shall return only the models on that client's allowlist.

## Acceptance Criteria

### AC-01

Given a client whose token is allowed only `model-a`, when it requests `model-a`, then the request is answered, and when it requests `model-b`, then it gets HTTP 403 and the provider records no request for `model-b`.

### AC-02

Given authentication enabled, when a request is sent with no `Authorization` header or with an unregistered token, then it gets HTTP 401 and the provider records no request.

### AC-03

Given the same client, when it calls `GET /v1/models`, then the returned list contains `model-a` and does not contain `model-b`.
