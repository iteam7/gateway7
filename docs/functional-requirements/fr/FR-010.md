# FR-010: Show Gateway Operations On The Overview Dashboard

- **Status:** Active
- **Traces to:** [`DEC-014`](../../decisions.md#dec-014)
- **Containers:** `prometheus`, `grafana`

## Behavior

When the monitoring stack runs beside the gateway, Prometheus shall collect the gateway's metrics under the job `gateway7` at the configured scrape interval.

Grafana shall serve the provisioned overview dashboard from those samples, showing request outcomes, provider outcomes and latency, and each middleware's outcomes and own-work duration, without an administrator login.

## Acceptance Criteria

### AC-01

Given the Compose stack started with `docker compose up --build --detach --wait`, when Prometheus is queried for `up{job="gateway7"}`, then the result is `1`.

### AC-02

Given the same stack after several chat requests, when `http://127.0.0.1:3000/d/gateway7-overview` is opened without logging in, then the dashboard loads and its chat-throughput panel shows the requests by status.
